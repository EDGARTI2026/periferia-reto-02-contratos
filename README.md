\# Reto 02 — Agente Conversacional: Registro de Contratos Vigentes



Solución al Reto Técnico 02 para la posición de \*\*Consultor de Estrategia IT\*\* en Periferia IT Group / Perxia 2.0.



Este proyecto implementa un agente enfocado en la gestión, clasificación y actualización de contratos en un maestro CSV, resolviendo la discontinuidad del proceso operativo y proporcionando reportes de alertas para la Alta Dirección.



\---
